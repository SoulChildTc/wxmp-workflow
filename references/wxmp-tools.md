## 爆款标题生成器

基于文章内容生成多个标题选项，帮用户找到最有吸引力的那个。

### 何时使用

- 用户写完文章后不知道怎么取标题
- 用户对现有标题不满意
- 用户说"帮我想几个标题"或"标题太普通了"

### 怎么做

1. 通读文章全文，理解核心观点和目标读者
2. 用以下 6 种策略各生成 2 个标题，共 12 个：
   - **口语法**：像跟朋友聊天一样自然（"说实话，XX 真没那么难"、"我试了 XX，结果出乎意料"）
   - **好奇法**：制造信息缺口（"这个方法让我月入 X"、"90% 的人不知道"）
   - **痛点法**：直击读者焦虑（"你还在 X？"、"为什么你总是 Y"）
   - **数字法**：用具体数字制造确定感（"5 个方法"、"3 分钟学会"）
   - **对比法**：制造反差（"从 X 到 Y，我只做了一件事"）
   - **权威法**：借助背书（"XX 亲测有效"、"行业大佬都在用"）
3. 每个标题必须与文章核心内容直接相关，不能为了爆款而偏离原文
4. 避免 AI 味标题：不用"赋能""助力""深度解析""一文读懂"等套路词
5. 每个标题附带一句话分析：为什么这样写、适合什么读者
6. 按推荐度排序，最推荐的放前面

**被否定后：** 如果用户否定一轮标题，先问"你想要什么感觉的标题？"（比如更口语、更正式、更夸张、更低调），再针对性生成

### 输出格式

```
🏷️ 爆款标题候选（共 12 个）

⭐ 推荐
1. 《xxx》— 口语法，像朋友聊天一样自然
2. 《xxx》— 好奇法，制造信息缺口吸引点击

📌 备选
3. 《xxx》— 痛点法，直击目标读者的核心焦虑
4. 《xxx》— 数字法，用具体数字降低阅读门槛
...

💡 分析：这篇文章的核心价值是 xxx，建议标题突出 xxx，避免 xxx。
```

## 摘要生成器

生成 120 字以内的公众号摘要，用于文章列表展示。

### 何时使用

- 用户不知道怎么写摘要
- 用户说"帮我写个摘要"或"摘要太长了"
- 在创建草稿前自动生成

### 怎么做

1. 通读文章，提炼核心观点
2. 摘要要满足：
   - 120 字以内（公众号限制）
   - 独立可读（不依赖标题）
   - 制造好奇心或承诺价值
   - 避免重复标题已表达的信息
3. 生成 3 个版本让用户选择：
   - **悬念型**：制造信息缺口，吸引点击
   - **价值型**：直接说明文章能给读者什么
   - **故事型**：用一个小故事/场景开头

### 输出格式

```
📝 摘要候选（共 3 个）

1. 悬念型：xxx
2. 价值型：xxx
3. 故事型：xxx

💡 建议：如果文章偏干货，选价值型；如果偏观点/故事，选悬念型或故事型。
```

## 文章体检报告

分析文章的可读性和传播力，给出具体优化建议。

### 何时使用

- 用户写完文章想优化
- 用户说"帮我看看这篇文章怎么样"
- 用户说"有没有什么可以改进的"
- 在转 HTML 之前做一次体检

### 怎么做

从以下 5 个维度打分（每项 1-5 分），并给出具体改进建议：

| 维度 | 检查什么 |
|------|---------|
| 开头吸引力 | 前 3 行是否能抓住读者？有没有制造好奇/痛点/悬念？ |
| 段落可读性 | 段落是否够短（≤4行）？是否有留白？是否适合手机阅读？ |
| 结构清晰度 | 小标题是否清晰？逻辑是否连贯？读者能否扫读？ |
| 金句密度 | 是否有值得划线/转发的句子？大约每 500 字一个金句？ |
| 结尾引导力 | 是否有互动引导（点赞/在看/评论/转发）？ |

### 输出格式

```
📊 文章体检报告

总体评分：xx/25

| 维度 | 评分 | 说明 |
|------|------|------|
| 开头吸引力 | x/5 | 具体分析... |
| 段落可读性 | x/5 | 具体分析... |
| 结构清晰度 | x/5 | 具体分析... |
| 金句密度 | x/5 | 具体分析... |
| 结尾引导力 | x/5 | 具体分析... |

🔧 优化建议：
1. 具体建议（对应哪个维度）
2. 具体建议
3. 具体建议
```

## 去 AI 味检查

AI 生成的文章有明显的"AI 味"——太完美、太中立、太工整、太空泛。去 AI 味是每篇文章打磨的必经步骤，目标是让文章读起来像一个有态度的人在聊天，而不是 AI 在交作业。

> 💡 如果已安装 [Humanizer](https://github.com/blader/humanizer) 和 [StopSlop](https://github.com/hardikpandya/stop-slop)，优先使用它们（Humanizer 去 AI 痕迹 → StopSlop 打磨质量）。以下为内置的兜底规则。

### 何时使用

- 文章写完后、体检报告之前
- 用户说"这文章一看就是 AI 写的"
- 用户说"帮我改得像人写的"
- 每篇文章必经步骤

### 怎么做

分 4 轮扫描，每轮聚焦不同层面：

#### 第 1 轮：查 AI 特征词

扫描以下高频 AI 词汇，找到就替换或删除：

**过渡词滥用（删除或换掉）：**
| AI 词 | 换成 |
|-------|------|
| 值得注意的是 | [删掉] |
| 需要指出的是 | [删掉] |
| 不仅如此 | 而且、还不止这些 |
| 与此同时 | 这时候、同一时间 |
| 换言之 / 换句话说 | [删掉，直接说] |
| 值得深入探讨 | [删掉] |

**空洞高级词（换成具体表达）：**
| AI 词 | 换成 |
|-------|------|
| 赋能 | 帮你、让...能 |
| 深耕 | 专注、一直做、埋头研究 |
| 打造 | 做、搞、弄 |
| 构建 | 搭、建 |
| 驱动 | 推动、带着走 |
| 助力 | 帮、让 |
| 旨在 | 就是想 |
| 致力于 | 一直在 |
| 颗粒度 | 细节、具体程度 |
| 底层逻辑 | 本质、根本原因 |
| 闭环 | 完整流程、从头到尾 |
| 场景化 | 结合实际场景 |

**套话开头/结尾（删掉或重写）：**
| AI 词 | 怎么改 |
|-------|--------|
| 在当今社会 | [删掉，直接切入] |
| 随着...的发展 | [删掉，用故事/数据开头] |
| 在这个...的时代 | [删掉] |
| 不可否认 | [删掉或换成"说真的"] |
| 毋庸置疑 | [删掉] |
| 众所周知 | [删掉] |
| 总而言之 / 综上所述 | [删掉，直接说结论] |
| 总之 | 所以说、反正 |

**模糊万能表达（换成具体）：**
| AI 词 | 换成 |
|-------|------|
| 在一定程度上 | [删掉或给具体程度] |
| 从某种角度来看 | [删掉或给具体角度] |
| 具有重要意义 | [具体说有什么意义] |
| 深远影响 | [具体说影响是什么] |
| 不容忽视 | [删掉] |
| 方方面面 | [具体列举] |

#### 第 2 轮：查结构问题

| 问题 | 怎么改 |
|------|--------|
| "首先...其次...最后" 刻板结构 | 换成自然过渡，或只保留重点 |
| 连续 3+ 个排比句 | 只留最有力的一个，其他换表达 |
| 每段都 3-4 句，长度差不多 | 长短交替：有的段一句话，有的展开讲 |
| 段落过渡太顺滑 | 允许逻辑跳跃，新段直接起新话题 |
| 总-分-总模板 | 换结构：故事先行、结论先行、夹叙夹议 |
| "一方面...另一方面" 两面讨好 | 亮明立场，敢下判断 |

#### 第 3 轮：查风格问题

| 问题 | 怎么改 |
|------|--------|
| 全文语气平淡，没有情绪起伏 | 加情绪高点：惊讶、吐槽、兴奋 |
| 大量用"我们"，称呼疏远 | 换成"你""我"，像跟朋友聊天 |
| 举例空泛："很多人""有研究表明" | 用具体的人、具体的数、具体的场景 |
| 过度客套："希望对你有帮助" | 删掉或换成有态度的结尾 |
| 没有个人观点，纯客观陈述 | 加"我觉得""说实话""我的经验是" |
| 成语用得太工整 | 少用四字成语，换成口语表达 |

#### 第 4 轮：加人味（必做）

检查文章是否有人的痕迹，没有就补：

| 人味元素 | 示例 |
|----------|------|
| 个人经历 | "我去年试过这个方法，结果翻车了..." |
| 具体细节 | "昨天微信更新到 8.0.44 之后..." |
| 明确立场 | "这方法就是垃圾，别浪费时间了" |
| 幽默/自嘲 | "我又踩坑了，这次是第 23 次" |
| 不完美的观点 | "我也没想明白，但先这么干着" |
| 反问/自问 | "这事儿靠谱吗？" |
| 断句/碎句 | "说白了。""问题是——" |
| 口语感 | "说实话""其实吧""你想想""怎么说呢" |

### 输出格式

```
🔍 去 AI 味检查

━━━ 第 1 轮：特征词 ━━━
❌ "赋能" → 改成"帮你"
❌ "值得注意的是" → 删掉
❌ "在当今社会" → 删掉，直接切入
...共 x 处

━━━ 第 2 轮：结构 ━━━
❌ 第 3-5 段长度雷同 → 长短交替
❌ "首先...其次...最后" → 删掉连接词，直接讲重点
...共 x 处

━━━ 第 3 轮：风格 ━━━
❌ 第 2 段举例空泛 → 补具体数据/案例
❌ 全文没有明确立场 → 在关键观点上表态
...共 x 处

━━━ 第 4 轮：人味 ━━━
⚠️ 缺少个人经历 → 建议在第 2 段加一个亲历故事
⚠️ 缺少口语表达 → 加入"说实话""你想想"等
...共 x 处

💡 AI 味评估：x/10（10=纯AI，1=完全不像AI）
```

## 话题标签推荐

根据文章内容推荐适合的公众号话题标签。

### 何时使用

- 用户说"帮我加几个标签"
- 在发布前自动推荐

### 怎么做

1. 提取文章的核心关键词（3-5 个）
2. 结合公众号热门话题，推荐标签
3. 每个标签说明为什么适合这篇文章

### 输出格式

```
🏷️ 话题标签推荐

推荐标签：
1. #关键词 — 理由
2. #关键词 — 理由
3. #关键词 — 理由

💡 标签不宜过多，3-5 个为佳。优先选搜索量大但竞争适中的标签。
```
